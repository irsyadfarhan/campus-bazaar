# CampusBazaar – Storyboard (HTML)

Storyboard / UI flow for the **Campus-Bazaar: Pre-loved Textbook & Gear Exchange** web application.

## How to view
Open `index.html` in any modern browser (double-click, no server or install needed).
Click through the pages using the navigation bar and buttons.

## Pages
| File | Screen |
|---|---|
| `index.html` | Dashboard / home |
| `login.html` | Log in / Sign up |
| `listings.html` | Browse listings, search & filter |
| `purchase.html` | Purchase request (buyer) |
| `cart.html` | Cart |
| `checkout.html` | Checkout |
| `order-placed.html` | Order placed |
| `chat.html` | Chat with seller |
| `create-item.html` | Create / edit item (seller) |
| `trading-posts.html` | Trading posts |
| `profile.html` | Profile |
| `admin.html` | Admin dashboard |
| `admin-reported-posts.html` | Admin: reported posts |
| `admin-users.html` | Admin: user accounts |

## Flow
Dashboard → Listings → Buy → Purchase → Checkout → Order placed → Chat with seller
Login/Sign up → Profile · Sell → Create item · Admin → Reported posts / User accounts

## Structure
`assets/fonts` (Poppins), `assets/images` (logo), `assets/js` (React + page runtime, bundled locally so it works offline).
